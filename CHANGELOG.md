# Changelog

## [0.2.0] - 2026-11-26

- `nsh-frameworks` and `nsh-maven` are now one crate and command, `nsh-native-deps`. README "Moving" lists what to change.
- `nsh-native-deps android add | remove | sync | list` replaces `nsh-maven`.
- `[package.metadata.nsh-native-deps]` takes `android`, the Maven libraries of a crate.

## [0.1.1] - 2026-11-26

- `nsh-frameworks` is now [`nsh-native-deps`](https://crates.io/crates/nsh-native-deps). No code changes; this is the last `nsh-frameworks` release.

## [0.1.0] - 2026-11-24

- First release on crates.io.
